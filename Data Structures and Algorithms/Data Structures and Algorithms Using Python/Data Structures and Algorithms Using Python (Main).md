# Data Structures and Algorithms Using Python

_Rance D. Necaise · Wiley, 2011_

A first course in data structures, taught through **abstract data types** in Python. Each chapter defines an ADT and implements it with one or more data structures, then uses it in an application. Each chapter ends with exercises and programming projects. Appendices A–D review the Python the book relies on.
